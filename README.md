# Physics in Code ⚛️💻

Programming is an interpretation of everyday life (and of physics) in a programming language.

This repository is a series of small, runnable examples. Each one takes **one idea from physics** and shows **the same idea in software**: the analogy, a short piece of code that demonstrates it, and the lesson for real projects.

It accompanies my [LinkedIn posts](https://www.linkedin.com/in/karine-babajanyan-942277189/) on the same topic.

## Topics

| # | Physics | Programming | Example |
|---|---|---|---|
| 1 | Schrödinger's cat | "It works on my machine": missing environment variables | [01-schrodingers-cat](./01-schrodingers-cat) |

More topics are on the way, from mechanics, thermodynamics, electricity, waves, relativity and fluids.

## Running the examples

Requires **Node.js 18+**. There are no dependencies to install.

```bash
cd 01-schrodingers-cat
node open-the-box.js   # run the demo
node --test            # run the tests
```
